# The add-ons this image comes with.
#
# One of two ways, and both work. This one is pinned, diffable and rebuilt
# the same on any machine, which is what a deployment wants. The other is the
# Add-ons page, which installs into the data directory -- a volume here, so
# what is installed that way outlives the container it was installed from.
#
# Use this for what the station must have when it comes up. A station whose
# console stops being read because somebody forgot to click something after
# a rebuild is the failure this file exists to make impossible.
#
# Pinned to commits, like everything else in this project that is compared
# against or depended on. A station that runs untouched for years should not
# have what it records decided by whatever was on a branch the morning
# somebody rebuilt.
#
# `--no-deps` in the Dockerfile, so this has to name what it needs: the push
# protocols share weewx-evo-push-common, and pip would otherwise go looking
# for it on PyPI, where it is not.
#
# Tarballs rather than `git+https://`. `git+` makes pip shell out to git, and
# git is a build tool with no business in a container that runs a weather
# station for years -- installing an add-on from the settings page then
# failed with "Cannot find command 'git'" on an image that was right not to
# have it. GitHub serves /archive/<commit>.tar.gz, which pins the same thing.

# The machinery the six push protocols share. Provides nothing on its own.
weewx-evo-push-common @ https://github.com/weewx-evo/weewx-evo-push-common/archive/52559665bb349e4cfa34d90745662b776fc0fd99.tar.gz

# Ecowitt custom upload: the console this station has.
weewx-evo-ecowitt @ https://github.com/weewx-evo/weewx-evo-ecowitt/archive/1e1ad54fb4ae1945da3c7a0b7b5ac7286dc84e01.tar.gz

# Running a WeeWX driver as a collector. Here because the configuration has
# collectors of that kind in it: without this the kind is unknown, they are
# skipped, and their endpoints do not exist.
#
# Without its `[usb]` or `[serial]` extras, and that is right: the driver
# runs where the hardware is, which is not this container. What this image
# needs from the package is the settings page and the endpoint.
weewx-evo-weewx-driver @ https://github.com/weewx-evo/weewx-evo-weewx-driver/archive/8d8fcd7f58a1458905234cd3534b2c26dcc11e9b.tar.gz
